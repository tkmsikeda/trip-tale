# 目的
旅行に行った後に、思い出を振り返りたいところですが、写真や動画が大量にあり振り返るのが大変で手間です。
自動で、全ての写真と動画を１個の動画にまとめるプログラムを目指します。

# みてねメディアの対象期間

orchestrator Lambda の環境変数で、ダウンロード対象の期間を指定します。

```text
TARGET_START_AT=2025-04-01T00:00:00+09:00
TARGET_END_AT=2025-04-15T00:00:00+09:00
```

期間の判定は、開始日時を含み、終了日時を含まない形式です（`TARGET_START_AT <= tookAt < TARGET_END_AT`）。
したがって、この設定では 2025年4月1日から4月14日までのメディアが対象となり、4月15日00:00以降は対象外です。
